Third-party SDK List

Last updated: November 24, 2026

UnicornPlayer is an offline-first local music player built mostly on local open-source libraries. The table below lists all third-party components and their data handling:

ComponentPurposeNetworkData involved
OkHttpHTTP client frameworkYesCarries only the "update check" (api.github.com) and "lyrics search" (lrclib.net) HTTP traffic
Media3 / ExoPlayerAudio playback engineNoPlays your local audio files
GlideImage loading (album art)NoReads embedded cover art from audio files for display
RoomLocal databaseNoStores library, playlists, and play history on the device
DataStoreLocal preferencesNoStores theme, language, playback state on the device
DocumentFileSAF file accessNoReads/writes files (e.g., lyrics) in directories you authorize
SmartRefreshLayoutPull-to-refresh UINoNone
MarkwonMarkdown rendering (user guide)NoNone
Gson / kotlinx-serializationJSON parsingFollows requestsParses the version-check response; sends nothing by itself
opencc4j / pinyin4jTraditional/Simplified conversion, pinyin sortingNoText conversion on local song titles

Notes

  • All components above are open-source libraries running locally on your device; none of them embeds data-collection code;
  • Only OkHttp performs network communication, limited to update checks and lyrics search. See the UnicornPlayer Privacy Policy for details;
  • If this list changes due to version upgrades, we will update the Privacy Policy accordingly and notify you in the App.
