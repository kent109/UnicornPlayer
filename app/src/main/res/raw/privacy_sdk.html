第三方 SDK 清单

更新日期：2026年11月24日

轻籁为离线优先的本地音乐播放器，使用的组件以本地开源库为主。下表列出全部第三方组件及其数据处理情况：

组件用途联网涉及的数据
OkHttp网络请求框架是仅承载"检查更新"（api.github.com）与"歌词搜索"（lrclib.net）的 HTTP 通信
Media3 / ExoPlayer音频播放引擎否播放您本地的音频文件
Glide图片加载（专辑封面）否读取音频文件内嵌封面并在界面显示
Room本地数据库否在设备本地存储媒体库、歌单、播放记录
DataStore本地偏好存储否在设备本地存储主题、语言、播放状态等设置
DocumentFileSAF 文件访问否按您授权的目录读写歌词等文件
SmartRefreshLayout下拉刷新交互否无
MarkwonMarkdown 渲染（使用指南）否无
Gson / kotlinx-serializationJSON 解析随请求解析检查更新的版本响应，不主动发送数据
opencc4j / pinyin4j繁简转换、拼音排序否对本地歌曲标题做文本转换

说明

  • 上表组件均为开源库，随应用安装在您的设备上本地运行，不内置任何数据采集代码；
  • 仅 OkHttp 参与网络通信，且仅用于检查更新与歌词搜索两个场景，详见《轻籁隐私政策》；
  • 若本清单因版本升级发生变化，我们会同步更新《轻籁隐私政策》并在应用内告知。
