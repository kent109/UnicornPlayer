# 多音字读音配置
#
# 通用规则：
# - 每行一条，格式为 "汉字或词语=拼音"（拼音小写、无声调、无空格分隔）
# - 以 # 开头的行为注释，空行用于分组
# - pinyin4j 对多音字只会返回内置的第一个读音（常为生僻读音，如"长远"被读成 zhangyuan），
#   本文件用于纠正读音。补充词条后无需改代码，重启即生效。
# - 仅声调不同的多音字不影响排序，无需收录。
#
# 文件分两段：
# [words] 多音词：匹配时最长词语优先（如"排行榜"优先于"排行"），词语读音最准确
# [chars] 单字常用读音：未命中任何词语时，按此表给单个汉字定音（如单独出现的"长"默认 chang）
# 解析顺序：[words] 词语匹配 → [chars] 单字读音 → pinyin4j 兜底
